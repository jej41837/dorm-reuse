# 기숙사 물품 재사용 서비스 목업

학생이 사용 가능한 물품을 둘러보고 예약하거나 물품 사진을 등록하고, 관리자가 등록 물품을 심사·입고·게시하는 서비스의 **동작하는 화면 목업**입니다. 성균관대학교 명륜학사 [공지사항 페이지](https://dorm.skku.edu/dorm_seoul/notice/notice_all.jsp?mode=list&board_no=78&pager.offset=0)의 색상과 메뉴·정보 구조를 참고했습니다. 비공식 시안이며 학교의 실제 서비스는 아닙니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다. 정적 웹 서버에서도 그대로 실행됩니다. 우측 상단의 **학생 화면 / 관리자 화면** 버튼으로 역할별 화면을 전환할 수 있습니다.

예시 데이터와 사용자가 바꾼 상태는 브라우저 메모리에만 있습니다. 새로고침하면 초기 예시로 돌아갑니다. 데이터베이스, 실제 로그인, 파일 저장 서버는 연결하지 않았습니다.

## 학생 화면

- **물품 둘러보기:** 학기와 카테고리별 물품 조회, 사진·상태·크기·수령 장소 확인
- **내 등록 내역:** 본인이 등록한 물품을 학기별로 조회하고 심사·입고·게시 상태 확인
- **물품 등록:** 카테고리 선택, 설명과 상태 입력, 참고 사진 첨부
- **내 예약:** 예약 물품과 수령 기한 확인

초기 카테고리는 생활용품, 수납·정리, 건조·세탁, 소형 가전, 기타입니다.

## 관리자 화면

- 학생이 등록한 사진과 설명을 검토해 승인 또는 반려
- 승인된 물품의 창고 입고 확인 후 게시
- 예약·수령·미수령 및 추가 배부 상태 관리
- 학기별 등록 수, 재분배율, 보관 부피, 처리 시간, 잔여량 확인

학생 등록 폼에서는 JPG·PNG·WEBP 사진을 최대 3장까지 선택하고 즉시 미리 볼 수 있습니다. 한 파일은 2MB 이하로 제한합니다. 심사용 사진과 등록 상태는 이 브라우저 세션에서만 유지됩니다.

물품 카드의 예시 사진은 내장 ImageGen으로 만든 `assets/catalog.png`를 사용합니다. 생성 요청은 “책상 정리함, 원목 옷걸이, 접이식 건조대, 패브릭 수납함, 전기포트, 스탠드를 3×2 배열의 일관된 스튜디오 제품 사진으로 만들고, 글자·로고·사람은 넣지 말 것”이었습니다.

## 운영 흐름

1. 학생이 물품 정보와 사진을 등록합니다.
2. 관리자가 검토합니다. 승인된 물품만 창고에 맡길 수 있습니다.
3. 관리자가 실물 입고를 확인한 뒤 게시합니다.
4. 학생이 게시된 물품을 예약합니다. 한 학생은 동시에 최대 5개까지 예약할 수 있습니다.
5. 예약 물품은 정규 입사 기간 동안 해당 학생에게 보장됩니다. 입사일에 입사 확인서를 검토합니다.
6. 기간 내 미수령 물품은 추후 추가 배부에서 선착순으로 배분합니다.

시범 운영은 기숙사 한 동에서 한 학기 동안 진행하고, 피드백을 반영해 확대하는 방향입니다. 정규학기 이후 한 학기 동안 재사용되지 않은 물품은 폐기 대상으로 관리합니다.
